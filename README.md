# 器件响应约束下的低维视觉动作特征联合Gaussian编码与稳健识别

本FYP研究：将视频动作压缩成16维视觉输入后，如何通过既定器件响应、软件校准和联合Gaussian编码，保留动作可分性，并在响应变化下实现稳健识别。

文档更新：2026年10月31日；最新已完成实验：2026年10月26日。当前处于**软件探索已完成、瓶颈定位与方案定型待完成**的阶段，尚未进行硬件实验，也尚未确认Gaussian相对Linear的稳定优势。

完整论证见[实验报告](docs/器件约束视觉动作识别_实验报告.md)；本页用于说明研究主线、预期交付和推进状态。

## 1 研究什么

研究由三个相互衔接的问题组成：

1. **视觉输入是否有效？** 16个数是否保留了区分动作的信息，而不只是表示全图变化量？
2. **Gaussian编码是否有价值？** 在相同数据、合理匹配的参数与分类头下，识别表现或响应变化下的表现是否获得可重复收益？
3. **器件约束会带来什么影响？** 实测响应经校准后能否接近目标Gaussian；Cycle变化、校准误差和额外软件计算会怎样影响分类？

研究重点是视觉输入与器件约束编码的适配，而不是重新发明Gaussian核、追逐KTH最高分，或预设Gaussian必须胜过Linear。Gaussian与Linear的差别还包含16到256维扩展及校准等因素，需要用对照分开解释。

当前范围为KTH六类、紧凑16维视觉特征、原项目定义的联合Gaussian与Ridge分类头。不引入CNN、光流、骨架、人体分割或跟踪，不模拟未知脉冲／电路动态，不通过神经网络自动学习Gaussian参数。

## 3 为什么使用KTH

前期HMDB51在当前低维表示下效果不理想，因此转用KTH做更受控的软件验证，不在首页展开前期细节。

KTH具有较统一的背景、固定相机、六类动作，以及官方按参与者划分的协议，适合先排查轻量输入与Gaussian编码的适配，再检查跨人变化。选择它不保证Gaussian更好，也不能把跨数据集分数变化全部归因于背景简化。[KTH官方说明](https://www.csc.kth.se/cvap/actions/)、[官方标注与划分](https://www.csc.kth.se/cvap/actions/00sequences.txt)。

六类为走路、慢跑、跑步、拳击、挥手、拍手。实际使用599个原视频中的2389个成功动作片段，划分为760训练、767验证、862测试，对应8／8／9名参与者。同一参与者、源视频及相同内容文件不跨集合。实验样本是标注子片段，不是2389个独立原视频。

## 4 计算原理

### 4.1 视频如何变成16个输入

每个官方动作片段取中间固定1秒，按实际FPS定位17个等间隔采样帧；灰度化、缩放为64×64，先转float32并除以255，再计算相邻帧绝对差。

已比较两种编码：

- 时间16维：每张帧差图取全图均值，保留16个时间间隔。
- 区域×时间16维：画面分为四个固定象限，16个帧差分成四个时间组，每个区域与时间组取平均，共4×4个数。这是当前软件候选，固定象限不是检测出的人体部位。

输入只除以对应训练部分所有数值的全局最大值，零最大值时除数用1；验证与测试使用该尺度并截断越界值。不逐视频或逐位置拟合缩放，交叉验证时每折重新用折内训练部分拟合。随后使用原项目的256个实际等级量化表。

### 4.2 器件响应如何形成联合Gaussian

```text
视频片段
  → 16维视觉输入 → 训练尺度缩放与原等级表量化
      ├─ Linear：训练输入标准化 → Ridge分类头
      └─ Gaussian：16×16实测响应
                    → 逐维逐通道训练标准化
                    → 每维17×256 Ridge校准
                    → 对应维度因子相乘，形成256维联合Gaussian
                    → Ridge分类头
```

设输入维度d=1…16，响应通道k=1…16，联合中心j=1…256。q是量化输入，c[j,d]是第j个联合中心的第d维坐标：

```text
H[n,d,k] = bank(q[n,d], Cycle[n], k)
Z[n,d]   = [1, (H[n,d,:] - mean[d,:]) / std[d,:]]
T[n,d,j] = exp(-(q[n,d] - c[j,d])² / (2σ²))
A[d]     = 用训练数据将Z[:,d]校准到T[:,d,:]的Ridge矩阵
F[n,d,j] = clip(Z[n,d] @ A[d], 1e-6, 1)
Φ[n,j]   = exp(sum_d(log(F[n,d,j]))) = product_d F[n,d,j]
scores   = [1, Φ] @ W；预测类别取argmax(scores)
```

每个输入维度有16路原始响应，校准矩阵包含截距，形状为17×256；16个对应维度的因子相乘后，每个联合中心产生一个输出，最终为256维。原始256路响应不等于最终256维联合特征，也不是旧版标量Gaussian求和。

中心、标准化、校准及分类头只由相应训练部分拟合，标准差下限为1e-12，截距不正则化。实测响应保留原幅值与符号。推理时Gaussian校准路径只读取响应H；直接读取q计算理想Gaussian的是独立软件诊断路径。

输入坐标有身份，不能要求只打乱输入后输出不变。分类头是one-hot Ridge，不是Softmax，保存的类别得分不解释为概率。原器件代码只读导入；软件校准与联合重建尚不能视为已由物理器件直接完成。

### 4.3 Gaussian调参研究什么

Gaussian本身的研究参数是目标宽度σ及256个16维联合中心的位置／生成策略；中心数量与既定计算定义保持不变。这里的σ是软件联合Gaussian目标宽度，不是修改实测器件曲线的物理宽度。

校准正则化α和分类头正则化α是配套参数，应单独报告，不能将它们带来的全部变化称为Gaussian非线性的收益。中心必须由训练数据生成，选参只使用训练／验证，Linear也按相同规则选择分类头参数。

最近一轮固定中心，比较σ=0.125／0.25／0.5、校准锚定α=0.001／0.01／0.1、头锚定α=0.01／0.1／1／10。结果仍选择σ=0.25，验证变化主要与分类头正则化有关。中心策略的进一步比较属于后续计划，不是本轮已完成内容。

## 5 研究如何推进，现在到哪一步

| 阶段 | 核心操作与完成标志 | 状态 |
|---|---|---|
| 1 模型与数据核对 | 明确器件计算、真实视频输入、划分、数值及训练限定预处理 | 已完成当前工程检查 |
| 2 软件探索与初步筛选 | 比较输入表示、Cycle训练及有限Gaussian参数，保存候选与负面结果 | 已完成初步探索 |
| 3 瓶颈定位 | 用匹配配置区分输入信息、理想映射、校准误差及跨人泛化的影响 | 当前重点，尚未完成 |
| 4 方案定型与受控优化 | 根据诊断固定输入，再有限选择Gaussian参数及稳健校准，复用条件一致的旧实验 | 待完成，已有探索不等于定型 |
| 5 冻结与确认性评价 | 预先固定方案、指标及评估安排，检查独立性与不确定性 | 未完成 |
| 6 小规模硬件验证 | 若软件证据支持，先核对输入—响应及校准一致性，再评价完整流程 | 未开始，条件性后续工作 |

下一步先做阶段3，不直接增加更大的参数网格：

1. 固定输入，匹配理想Gaussian和响应库Gaussian的中心、宽度及等价分类头正则化，同时保留Linear参照。先在训练／验证部分分析，不增加测试候选来追分。
2. 重点检查拳击—拍手、慢跑—走路，以及按人划分的错误。如果理想路径也弱，优先检查输入和映射适配；如果理想路径较好而响应库路径较差，优先检查校准与响应变化；训练较好但跨人较差，则检查泛化问题。这些是诊断线索，不是仅凭一个分数下结论。
3. 诊断后再预先限定一至两种仍为16维的输入候选，或一组有边界的Gaussian参数比较。一次只改一个关键因素，Linear与Gaussian使用公平的选择规则。

现有测试集已多轮查看，不能重新随机划分后声称获得全新的独立验证。后续确认性结论需要明确的独立评估安排。

## 6 已完成实验提供了什么证据

已完成原器件模型核对、G0／G1／G2 Cycle训练、两种16维输入对照，以及固定新输入的有限调参。完整阶段结果见[实验报告](docs/器件约束视觉动作识别_实验报告.md)，不同模型与Cycle协议的分数不视为同一次控制实验。

最新有限调参共88个候选：72个Gaussian、4个Linear和12个理想软件诊断。默认条件一致的4个分类头与1个校准直接复用。G0用训练Cycle均值拟合校准和头；G1保持同一校准，每个训练片段用8个Cycle训练分类头。参数按验证Macro-F1优先锁定后，再评价测试。

| 方案 | 调整前测试准确率 | 调整后测试准确率 | 调整后Macro-F1 |
|---|---:|---:|---:|
| Linear | 50.58% | 50.81% | 0.4763 |
| G0 均值训练 | 53.72% ± 0.69% | 53.56% ± 1.01% | 0.5293 |
| G1 分类头Cycle训练，验证预选 | 53.60% ± 0.59% | 54.01% ± 0.62% | 0.5322 |

Gaussian数值为同一862个片段的10轮测试Cycle抽样均值，±仅为响应抽样标准差，不是跨人误差或10倍独立视频。Cycle索引按seed=42固定240／80／80训练、验证、测试子集，所有方案共享相同抽样。

当前验证预选的软件候选为区域×时间16维、256个训练中心、σ=0.25、校准锚定α=0.001、G1头锚定α=0.01。采用`sum_alpha = anchor_alpha × 实际拟合行数 / 760`保持平均损失正则化一致，因此G1的6080行实际头α=0.08；这仍只来自760个训练片段。Linear头α=10。详见[实际参数](outputs/kth_spatiotemporal_tuning_v1/final_parameters.json)。

当前证据的限制：

- G1仅提高0.42个百分点。相对调后Linear的3.20个百分点差异，其探索性配对95%区间为−1.31至+7.45个百分点，尚不能认定稳定优势。
- 训练人群4折中G1由56.05%变为55.67%，调参收益没有同步出现。
- 拳击→拍手错误由58.81%降至52.52%，但走路、挥手及拍手召回率有退化，改善不是各类一致。
- 独立选择的理想软件参考为61.14%，使用另一宽度0.5；不是硬件成绩或精度上界，其与响应库路径的全部差距不能直接归因于器件。这也是下一步需要做匹配诊断的原因。

已保存的检查记录包含25项通过的单元测试及8个最终模型的得分／类别重载核对。这证明当前实现可复查，不代表已经证明识别价值。最新主流程实测20.20秒、CPU运行且Torch／BLAS各限1线程、未用GPU、峰值RSS约727.6 MiB；不是硬件时延或能耗。见[检查记录](outputs/kth_spatiotemporal_tuning_v1/verification.json)、[测试记录](outputs/kth_spatiotemporal_tuning_v1/test_results.json)及[成本](outputs/kth_spatiotemporal_tuning_v1/cost_and_environment.json)。

当前结论：保留G1为软件候选，继续研究，但暂不支持直接进入完整硬件实验；不据此认定整个数据集、动作任务或Gaussian器件不可用。
