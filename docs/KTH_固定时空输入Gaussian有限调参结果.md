# KTH固定时空输入Gaussian有限调参结果

2026年10月26日。研究方向为器件响应约束下的低维视觉动作特征联合Gaussian编码与稳健识别。本轮只做软件实验，不操作硬件。

## 本轮结论

固定4区域×4时间组的16维输入后，验证选中G1，目标sigma仍为0.25，校准alpha=0.001，分类头锚定alpha=0.01。测试Cycle准确率由53.60%升至54.01%，Macro-F1由0.5209升至0.5322；调整后的Linear为50.81%。拳击→拍手错误由58.81%降至52.52%，但其他类别有退化，跨人4折也没有改善。当前只支持小幅软件改进，尚未证明Gaussian有稳定优势，暂不支持直接进入完整硬件实验。

## 一 固定条件与有限搜索

复用本地KTH六类、599个原视频和2389个成功动作片段。官方参与者划分仍为760训练、767验证、862测试，各人及源视频不跨集合。输入是上轮保存的4个固定画面区域×4个时间组，位置顺序、17帧采样、灰度缩放和帧差算法均未修改。本轮没有重新解码、下载或重新提取特征，旧实验输出保留。

后端仍严格遵循原器件项目的软件计算：

```text
16个有身份的输入坐标
→ 原项目256级量化
→ 逐维查16通道实测响应，H为[N,16,16]
→ 训练样本逐维逐通道均值与标准差
→ 每维含截距的17×256 Ridge校准
→ 因子裁剪到[1e-6,1]
→ 同一联合中心的16个因子相乘，按exp(sum(log(factor)))实现
→ 256维联合Gaussian特征
→ one-hot Ridge分类头，得分argmax
```

这不是旧标量Gaussian求和，也不是把256个原始响应直接作为最终联合特征。输入坐标有区域和时间身份，不要求仅打乱输入仍保持输出不变。分类头得分不是Softmax校准概率。源项目只读导入，响应曲线、峰值、裁剪和核数没有修改，sigma表示软件联合Gaussian目标宽度，不表示改变物理器件曲线。

256个中心固定复用上轮由训练输入拟合的KMeans中心，不再搜索中心位置。统一输入缩放及统计也按相同训练数据复用，不使用验证或测试拟合。训练全局最大值仍为0.1383846402168274；验证仅1/12272个输入值截断，测试截断0。

| 参数 | 候选 |
|---|---|
| 联合Gaussian目标sigma | 0.125、0.25、0.5 |
| 校准锚定alpha | 0.001、0.01、0.1 |
| 分类头锚定alpha | 0.01、0.1、1、10，Linear与Gaussian相同 |
| Gaussian峰值与因子裁剪 | 峰值1，裁剪[1e-6,1]，固定 |
| 256个联合中心 | 训练拟合的原中心，固定 |

G0以训练Cycle均值拟合校准与分类头；G1使用完全相同的校准，只让分类头接触原有每片段8个训练Cycle响应。比较72个Gaussian候选、4个Linear候选，另有12个理想软件RBF诊断候选，总计88个。理想RBF不参与器件方案选择。

这里“默认”特指上轮新输入实验的固定配置，不是最初其他数据集的原保存权重。默认Gaussian为sigma=0.25、校准alpha=0.01、分类头锚定alpha=0.1；默认Linear头alpha=1。

## 二 验证选择和实现检查

Cycle仍用seed=42划分240训练、80验证、80测试索引；G1训练8个Cycle的抽样与上轮逐项一致，一段响应的所有输入维度及通道共享同一个Cycle。验证10轮seed=2042至2051，测试10轮seed=3042至3051；旧模型、默认指标及预测直接复用，不重复拟合。附加1%至5%模拟器噪声仅作次要诊断，不用于选参数。

先保存88个候选的每轮验证结果，再锁定每类方案参数。主依据是验证Cycle Macro-F1均值，其次为准确率、较小的F1抽样标准差；再并列优先默认、较简单方案、接近原宽度和校准正则化、较大头部alpha及固定ID。锁定文件写出后才评价新模型的测试表现，没有根据测试重新选参数。原测试集此前已被查看，本轮是探索性筛选，不是独立最终验证。

各方案采用相同平均损失正则化约定。原Ridge代码的求和形式alpha为：

```text
sum_alpha = anchor_alpha × 实际拟合行数 / 760
average_loss_lambda = anchor_alpha / 760
```

截距不惩罚。因此新G0头的实际alpha=0.01，而新G1有6080行，实际alpha=0.08；不是给G1八倍数据却保持不同的正则化强度。每折也按自身拟合行数换算。校准只使用训练均值响应，与G1的6080行分类头训练分开。

25项单元测试通过，其中4项是新增搜索规则、默认配置、独立Gaussian乘积及正则化换算测试。最终8个模型所有样本与抽样轮次的得分和预测重载复现，容差atol=rtol=1e-11。校准与分类头正规方程残差、训练响应统计、固定中心、Cycle配对和4折训练限定也核对通过。Ridge直接求解，不存在逻辑回归迭代未收敛问题。

训练8人内部相同4折只对已锁定配置做复核，没有扩展网格。每折用该折训练部分的缩放、中心、响应标准化和校准，参与者不重叠。旧折缓存条件一致时复用，未在全体训练样本上先拟合后再划折。

## 三 主结果与实际采用参数

训练列为760个训练片段在训练均值响应上的准确率；G1实际6080训练行的表现另存候选CSV。验证和测试列为各自10轮Cycle抽样的均值，±表示同一批片段的响应抽样标准差，不是跨人置信区间。

| 方案 | 训练均值准确率 | 验证Cycle准确率 | 验证Macro-F1 | 测试Cycle准确率 | 测试Macro-F1 |
|---|---:|---:|---:|---:|---:|
| Linear默认 | 52.76% | 53.19% | 0.4980 | 50.58% | 0.4758 |
| Linear调整 | 53.03% | 54.76% | 0.5100 | 50.81% | 0.4763 |
| G0默认 | 70.66% | 57.11% ± 0.45% | 0.5544 | 53.72% ± 0.69% | 0.5233 |
| G0调整 | 74.21% | 57.00% ± 0.91% | 0.5603 | 53.56% ± 1.01% | 0.5293 |
| G1默认 | 69.74% | 57.28% ± 0.69% | 0.5564 | 53.60% ± 0.59% | 0.5209 |
| G1调整，验证预选 | 72.76% | 57.77% ± 0.69% | **0.5674** | **54.01% ± 0.62%** | **0.5322** |

调整后的Linear采用头alpha=10。G0和G1均采用sigma=0.25、校准alpha=0.001、头锚定alpha=0.01；实际G1头alpha=0.08。两者校准训练相同，只是头部训练响应不同。继续保留256维联合特征、Ridge分类、seed=42及原响应库约束。

G1调整后测试提高0.42个百分点，Macro-F1提高0.0113；比调整后Linear高3.20个百分点。G0的测试准确率反而降低0.16个百分点，但Macro-F1增加0.0059。不能把“验证F1提高”写成“所有方案的测试准确率都提高”。

对9名测试参与者和10轮响应进行配对bootstrap，2000次、seed=42，G1调整减默认的探索性95%区间为−0.96至+1.69个百分点；调整G1减调整Linear为−1.31至+7.45个百分点，均包含0，尚不支持稳定优势。G1测试抽样标准差从0.59升至0.62个百分点，噪声附加条件为53.76% ± 1.09%，不能据此宣称稳健性全面提高。

## 四 哪些参数真正产生了变化

以下消融只比较已有验证结果，不增加测试配置，也不改变选择规则。

| G1验证比较 | 验证Macro-F1 |
|---|---:|
| 原固定配置：sigma=0.25，校准0.01，头0.1 | 0.556431 |
| 只将头改为0.01 | 0.567159 |
| 只将校准改为0.001，头仍0.1 | 0.555226 |
| 同时将校准改为0.001、头改为0.01 | 0.567446 |
| 只将宽度改为0.125，其他默认 | 0.521859 |
| 只将宽度改为0.5，其他默认 | 0.544017 |

本轮验证改善主要与分类头正则化有关；在头已经为0.01时，校准alpha再从0.01降至0.001只增加约0.00029的验证F1。宽度仍选原0.25，不能把本轮收益解释为“调Gaussian宽度成功”。这是验证集消融，不能据此精确分解测试集的收益。选中校准和头参数位于本轮下边界，也不能称为全局最优；本轮没有自动继续扩搜。

响应库联合特征相对同配置理想特征的测试Cycle RMSE约为15.76%至15.77%，调整前后几乎未变；均值响应误差约14.95%至14.94%。分类变化不能解释成校准重建误差大幅改善。

直接软件理想RBF的验证预选配置为sigma=0.5、头alpha=0.01，测试准确率从59.51%升至61.14%，F1从0.5957升至0.6068。这条路径不使用器件响应，且与选中G1的宽度不同；它不是硬件成绩或保证的上界，也不能把其与54.01%的全部差额归因于校准。

## 五 拳击有所改善但并非各类一起提高

| G1类别召回率 | 默认 | 调整 |
|---|---:|---:|
| 走路 | 60.63% | 58.26% |
| 慢跑 | 29.38% | 32.85% |
| 跑步 | 65.83% | 65.63% |
| 拳击 | 25.03% | 32.73% |
| 挥手 | 64.58% | 62.99% |
| 拍手 | 76.08% | 71.61% |

拳击→拍手错误从841/1430次降到751/1430次，即58.81%降至52.52%。1430来自143个拳击片段各10轮响应抽样，不是1430个独立视频。拳击与慢跑改善，拍手、走路和挥手退化；总体小幅提高伴随类别间权衡，不能称为已解决拳击与拍手混淆。

场景d2的G1准确率从31.34%升至33.06%，仍明显较弱；d4从56.67%降至56.06%。当前未隔离人物尺度、位置或具体背景因素，这些仍是可能原因，不是已证实结论。

| 训练人群内部4折 | 默认准确率 | 调整准确率 | 默认F1 | 调整F1 |
|---|---:|---:|---:|---:|
| Linear | 49.55% ± 5.68% | 49.81% ± 5.84% | 0.4659 | 0.4655 |
| G0 | 55.79% ± 4.49% | 54.70% ± 4.11% | 0.5458 | 0.5372 |
| G1 | 56.05% ± 3.85% | 55.67% ± 4.05% | 0.5487 | 0.5470 |

这里±为折间标准差。G1在官方验证、测试均值上略好，但训练人群内部4折未同步改善，支持“有限收益、跨人稳定性尚不足”的判断。不能用这一复核结果反过来挑正式测试配置。

## 六 当前采用什么以及下一步检查什么

本轮软件候选锁定为4区域×4时间组输入、256维联合Gaussian、sigma=0.25、校准alpha=0.001、G1头锚定alpha=0.01（6080行实际alpha=0.08）。同时保留默认G1、调后G0及头alpha=10的Linear作对照，不把小幅提高写成已经满足硬件实验条件。

本轮没有证实“宽度默认设置不当”是主要瓶颈，也没有发现需要修复的实现错误。有限校准正则化变化对重建误差作用很小，而理想软件参考也只有约61%；当前16维运动量的类别区分度和跨人泛化值得优先检查。应停止仅为提高已查看测试分数而扩大网格，先分析训练／验证中拳击与拍手、慢跑与走路的特征重叠，以及类别和人物的校准误差，再决定是否单独改输入编码。输入、校准和分类头不要同时改动。

研究方向仍可保留“器件响应约束下的低维视觉动作特征联合Gaussian编码与稳健识别”，但应研究Gaussian在哪些输入和响应扰动下有益，而不是预设它必须明显胜过Linear。Gaussian相对Linear的差异同时包含联合非线性映射、16到256维扩展和校准误差，不全部归因于Gaussian非线性。

当前16维输入与所测高斯方案效果和稳定性仍不足，暂不支持直接进入完整硬件实验。这不表示KTH、所有动作任务或器件永久不可用。源Excel仍未找到，Cycle评估只覆盖既有处理后响应库索引留出，不证明跨器件、跨批次、真实在线时序或原始测量全链路独立性。

## 七 运行成本和复现

主流程实测20.20秒，包括缓存与源文件核对、88候选搜索、锁定配置4折复核、评价、输出和模型重载检查；其中候选搜索5.90秒、4折1.21秒、锁定评价与保存6.88秒。图表与配对分析另见`analysis_summary.json`，不计开发和写文档时间。本轮视频解码和下载均未发生，不把0秒解释为测得的传输速度。

CPU型号记录为Intel Core i7-14700KF，系统报告28个逻辑CPU、总物理内存约15.53 GiB。Torch与BLAS各限1线程，未用GPU；主进程实测峰值RSS约727.6 MiB。模型存储与RSS不是同一概念，未测硬件时延或能耗。

搜索阶段复用4个默认头和1个默认校准，新增84个头及8个校准。旧4折对应模型和结果保留；对4个已选方案各4折新增16个分类头，共用参数相同的校准。旧图像和输入缓存直接使用，没有为统计重新载入原视频帧。
