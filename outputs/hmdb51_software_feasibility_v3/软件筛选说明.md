每核对16个输入计算高斯响应并求和，每核输出1值，共16维。旧B符合；旧C保留位置，不符合目标。100次排列检查通过，预测未变。G调整测试准确率/Macro-F1为18.18%/0.1752，A为17.05%/0.1538，G默认为18.75%/0.1604。调参未提高准确率，相比A仅小幅改善。当前16维输入与所测高斯方案效果不足，暂不支持直接进入硬件实验。先检查输入和错误来源；保留软件候选：训练P1～P99均匀16中心、σ=0.05、StandardScaler+逻辑回归C=10。差异包含高斯映射与求和；本轮仅为探索性筛选。

## 参数与判断依据

软件候选采用 `uniform_p01_p99`，完整训练拟合后中心为 `linspace(0.000290541, 0.250112758, 16)`，σ=0.05、峰值=1、每核全部16输入求和、16维输出；StandardScaler+多分类逻辑回归C=10，lbfgs、L2、max_iter=5000、tol=1e-6、seed=42。单位始终是缩放后的输入坐标，不赋予未知脉冲时间或电流单位。全部实际中心在 actual_model_parameters.json，模型在 models/。这是保留以供软件复核的候选，并非进入硬件的推荐配置。

选定G在176个测试视频中正确 32 个、错误 144 个；较多错误为 walk→wave：13个；jump→wave：12个；wave→sit：10个；walk→stand：10个；run→sit：10个。这种识别水平和类别混淆，不足以支持当前六类动作识别目标直接进入硬件。该判断没有设定事先的准确率门槛，也不只依据是否高于随机猜测。它仅针对当前16维输入和本轮所测Gaussian配置，不代表HMDB51永久不可用或器件不可行。

特别是walk类为 0/30 正确，不能用总体的小幅提升掩盖单类失效。各类的精确率、召回率、F1和预测数量见 per_class_metrics.csv。

推荐下一步仍在软件中检查当前平均帧差对人物动作、背景活动与镜头变化的区分能力，以及窗口是否覆盖动作。本轮没有改变输入、视频预处理或器件模型。A与G的差别同时包含Gaussian映射与求和，不能全部归因于Gaussian非线性。旧C的256维位置展开不满足本轮目标的顺序无关要求，其旧成绩没有纳入此处的目标可行性比较。

## 选择与复用

本轮候选为2种中心×3种宽度×3种分类器C（18组G）及3组A，共21组、63个折内拟合；它们的样本、3折清单、原始缓存、缩放、中心公式、分类器设置、代码AST及依赖均核对一致，因此全部复用，未重训CV。G默认固定均匀[0,1]、σ=0.1，但分类器C也按相同规则选择；所以它未必等于旧B(C=1)。本轮G默认的C=10，G调整的C=10，A的C=0.1。

选择规则预先保持为：mean validation Macro-F1 desc; mean validation accuracy desc; Macro-F1 SD asc; C asc; configuration ID asc。限制搜索空间是在查看本轮测试评价之前固定的；参数和混淆矩阵展示对象在 parameters_frozen_before_test.json 锁定。正式测试集此前已查看过，属于探索性软件筛选，不是独立最终验证。没有可靠同源ID，沿用既有分层3折并说明可能存在同源/同场景跨折，不猜测来源分组。

运行耗时、复用和新增拟合数见 runtime.json 与 final_model_fit_provenance.json。复用的旧fit耗时保留在CV表中并明确标注历史来源，不计为本轮新训练耗时。无GPU、无硬件操作、无下载。输入排列核查和重复值累加的逐项结果见 order_independence_checks.json，容差在模型拟合前固定。
