# KTH原器件标准流程软件实验

本轮直接复用原器件项目代码和实测响应库，训练KTH自己的中心、校准权重与六类Ridge分类头。模型为16维输入→16×16响应→逐维逐通道标准化→17×256 Ridge校准→跨维因子相乘→256维联合Gaussian→Ridge分类。它不是旧的16维求和模型，输入位置不能随意打乱。

严格保持因子裁剪[1e-6,1]，只以官方验证集选择参数，使用760训练、767验证、862测试片段。默认G测试47.68%／Macro-F1 0.4728，调整G为52.67%／0.5216，同类Ridge头的标准化Linear为44.90%／0.4377。默认G仅调分类头也达到50.12%，说明不能将全部改善归因于宽度。

推荐下一轮固定参照：256个训练KMeans中心、seed=42、目标sigma=0.25、校准alpha=0.01、分类头alpha=0.1，截距不正则化，标准差下限1e-12，因子裁剪[1e-6,1]。这是软件候选，不是硬件部署结论。

扩展裁剪上界1.2的55.45%分支在完整表中明确标为软件诊断，不代替严格模型成绩。Cycle抽样下严格调整G平均49.54%，再加原模拟器噪声为49.22%；10次抽样的波动不等于跨人验证误差。拳击仍有71/143段错为拍手，整体识别水平尚不足以直接进入完整硬件实验。

建议研究方向为“器件响应约束下的低维视觉动作特征联合Gaussian编码与稳健识别”。先在输入不变的条件下研究训练期Cycle感知校准，再单独检验16维空间与时间运动编码；不预设Gaussian必须胜出。当前属于探索性筛选，测试集之前已查看，不作为独立最终验证。
